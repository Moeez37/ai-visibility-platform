# AI Visibility Dashboard

Angular 21 dashboard for the API. Full details are in the [root README](../README.md).

```bash
npm install
npx ng serve
```

Open http://localhost:4200. The backend must be running on port 5000. To point at a different API, change `apiUrl` in `src/environments/environment.ts`.

Run the tests with `npx ng test --watch=false`.
